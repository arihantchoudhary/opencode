# Slack Integration — `packages/slack/`

Slack workspace bot for Stardrop.

**Version**: 1.1.42

## Features

- Slash commands (`/stardrop`)
- Message handling and responses
- Authentication with Slack OAuth
- Session creation from Slack messages

## Environment Variables

From `.env.example`:
- `SLACK_BOT_TOKEN`
- `SLACK_SIGNING_SECRET`
- `SLACK_APP_TOKEN`
