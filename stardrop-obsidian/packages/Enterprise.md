# Enterprise — `packages/enterprise/`

Multi-tenant enterprise features for Stardrop.

**Version**: 1.1.42

## Tech Stack

- **Framework**: SolidJS Start (metaframework)
- **HTTP**: Hono
- **API**: Nitro
- **AWS**: AWS4Fetch for API access
- **Deploy**: Cloudflare Workers

## Features

- Multi-tenant workspace isolation
- SSO integration
- Team management with roles
- Advanced permission policies
- Audit logs
- Usage quotas and billing
- Session sharing with access controls
